# Project Trident: Autonomous Marine Intelligence

Project Trident is a smart underwater robot concept built to monitor ocean oil leaks and guard marine life in UAE waters. 

## 🛠 Tech Stack
- **Hardware:** ESP32, TDS Sensor, pH Sensor, Turbidity Sensor, Ultrasonic Sensors.
- **Languages:** C++, JavaScript, HTML/CSS.
- **Cloud:** Google Apps Script & Google Sheets API.

## 🚀 System Architecture
1. **Firmware:** Reads 5+ environmental sensors and handles WiFi transmission.
2. **Backend:** Google Apps Script receives data via HTTP GET and logs it to a cloud database.
3. **AI Dashboard:** Rule-based logic categorizes pollution levels and suggests remedies.
4. **Navigation:** Autonomous obstacle avoidance with emergency distress signaling.

## 🇦🇪 Alignment
Developed to support **UAE Vision 2030** and **UN SDGs 6, 9, 11, and 12**.
